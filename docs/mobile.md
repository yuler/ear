# 手机端:局域网镜像设计

状态:原型阶段。交互原型在 `prototypes/ios/`,确认后再用 nsh 的 iOS/Android 目标实现。

## 目标

- 手机端只做一件事:把电脑上已经下载好的视频和字幕镜像到手机,离线播放。
- 手机端不解析链接,也不从 YouTube 下载。下载只在电脑上做。
- 尽量少操作:配对一次之后,回到同一个 Wi-Fi 就自动同步,不需要手动点「同步」。

## 角色

- **电脑(Server)**:Ear 桌面端,是媒体库的唯一来源。它在局域网里提供镜像服务。
- **手机(Client)**:Ear 手机端,镜像电脑上的媒体库。
- **多对多**:
  - 一台电脑可以配对多台手机或平板,各自独立镜像。
  - 一台手机可以配对多台电脑,比如家里一台、公司一台。

## 配对

只支持局域网扫码。

1. 电脑打开「设置 → 手机镜像」,显示二维码和 4 位配对码。
   - 二维码内容:`ear://pair?transport=lan&host=<ip>&port=<port>&code=<配对码>`。
   - 配对码 2 分钟过期后自动刷新,用过一次也会立即刷新。
2. 手机扫码。手机必须和这台电脑在同一个 Wi-Fi,否则提示「不在同一个 Wi-Fi」。
3. 电脑弹窗「『这台 iPhone』请求配对」,并显示配对码供核对。用户在电脑上点「允许」或「拒绝」。
4. 允许后:
   - 手机出现在电脑的「已配对设备」列表里。
   - 这台电脑出现在手机的「已配对的电脑」列表里。

解除配对有两种方式,两种都会保留手机上已经下好的副本:
- 手机端:在「已配对的电脑」里点「断开」。
- 电脑端:在「已配对设备」里点「移除」。被移除的手机会看到提示。

## 多台电脑

典型场景:白天连公司电脑,晚上连家里电脑,两边的视频都传到同一部手机。

- **不需要手动切换。** 手机连上哪个 Wi-Fi,就自动连接那个网络里已配对的电脑。如果两台电脑在同一个网络,两台同时连。
- **只有一个媒体库。** 所有电脑的视频合在一起显示,每个条目标出来源,比如「家里」「公司」,或者「家里 · 公司」。
- **同一个视频只传一次。** 用 `videoId` 去重:家里已经传过的视频,在公司不会再传一次。
- **换网络时不丢进度。** 正在传的文件如果它的电脑突然连不上了,会回到等待状态。到了另一台也有这个视频的电脑上,会从那台电脑接着拉。
- **不在当前网络的电脑。** 它的视频显示「在家里 · 待连接」,回到那个 Wi-Fi 后自动镜像。
- **断开某一台电脑。** 只影响这台电脑:它独有、还没传完的条目会从列表消失;已经下好的副本保留,标为「来自家里」。

## 镜像规则

- **镜像范围**:默认镜像每台已配对电脑的全部媒体库(视频和字幕)。
- **新增视频**:电脑上新下载的视频会自动排进队列。
- **并发**:每部手机最多同时传 3 个文件,这个上限对所有电脑一起算(手机的带宽是共用的)。
- **中断**:断开 Wi-Fi、打开 Offline Mode、解除配对时,正在传的文件回到等待状态,条件恢复后继续传。
- **后台**:App 切到后台后镜像继续进行,用实时活动(Live Activity)或通知显示总进度,例如「后台镜像中 4/6」。
- **删除**:在手机上左滑删除,只删手机上的副本,不影响电脑。被删的条目移到「仅在电脑上」分组,不会再自动镜像,点「重新镜像」可以恢复。

## 手机端界面

### 媒体库(首页)

- **顶部状态条**,按情况显示一种:
  - 尚未配对电脑
  - 没有连上已配对的电脑(附上当前 Wi-Fi)
  - 镜像中 N/M · 同时 K 个 · 从哪些电脑拉取(附总进度条)
  - 已与哪些电脑同步。如果还有其他电脑上的视频没传,会说明还有几个。
- **状态条右侧**:没有配对时是「扫码配对」按钮;配对后显示「电脑 · N」,点开是「已配对的电脑」面板。
- **列表**:每行是一个视频,显示封面、时长、标题、状态标签、来源和文件大小。
- **状态标签**:
  - 已离线
  - 镜像中 xx%(封面底部还有一条进度线)
  - 等待镜像
  - 在家里 · 待连接
  - 重新镜像(按钮)
- **只有已离线的视频能打开播放。**
- **左滑**:露出「删除」按钮,滑得够长直接删除。
- **Offline Mode**:只显示手机上已经有的视频,并且暂停镜像。
- **空状态**:没有配对、手机上也没有视频时,显示「配对电脑后,媒体库会自动镜像到这里」和一个扫码配对按钮。

### 已配对的电脑(底部面板)

- 每台电脑一行,显示名称、是否已连接、所在网络、已传数量(N/M),以及「断开」按钮。
- 面板底部有「＋ 配对新的电脑」按钮,点了直接打开扫码。
- 配对失败或被拒绝时,面板顶部显示提示。

### 播放器

- 上下布局:16:9 视频固定在上方,下方是跟随播放滚动的字幕,底部是一排拇指可及的控制按钮。
- 控制按钮:盲听遮罩、上一句、播放/暂停、单句循环、下一句。右上角调倍速(0.8 / 1.0 / 1.2 / 1.5)。
- 点击字幕行,跳到那一句播放。

### 外观

- 黑白两种模式,配色和 `app/theme.json` 一致,默认跟随系统。

## 原型

用浏览器直接打开 `prototypes/ios/ios-mvp.html`,不需要构建,所有状态只保存在内存里。

**文件:**
- `ios-transport.js`:`Transport` 接口(只有 LAN,预留了 `TODO(relay)`)
- `ios-sync.js`:配对和镜像引擎,不依赖 DOM
- `ios-mac.js`:电脑端面板(家里 / 公司两台,可以切换)
- `ios-player.js`:播放器
- `ios-mvp.js`:手机界面、配对管理、手势、启动
- `ios-mvp.test.cjs`:引擎回归测试,用 `node --test prototypes/ios/*.test.cjs` 运行,CI 也会跑

**顶栏的模拟按钮:**
- 手机 Wi-Fi:在家里 / 公司 / 外出之间切换。
- 切到后台。
- 右侧电脑新下好 1 个视频。
- 其他设备配对到右侧电脑。
- 黑 / 白。

**原型没做的部分:**
- 二维码是假的,不能真扫。
- 没有真实网络传输,也没有加密和认证。
- 其他设备的镜像进度是模拟的。

## 待决定
